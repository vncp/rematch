## Install

<Tabs syncKey="harness">
<TabItem label="omp">
```sh
scripts/install.sh
rematch doctor --text    # ready: true
```
</TabItem>
<TabItem label="Claude Code">
```sh
cargo build --release
ln -s /path/to/rematch/adapters/claude-code ~/.claude/skills/rematch
```
</TabItem>
<TabItem label="Pi">
```sh
cargo build --release
pi install "$PWD/adapters/pi"
```
Pi 1.4.x, from a Rematch checkout.
</TabItem>
<TabItem label="OpenCode">
Add the checkout path to OpenCode's `plugin` array:
```json
{ "plugin": ["/path/to/rematch/adapters/opencode"] }
```
Build Rematch first. Tested with OpenCode 1.19.4.
</TabItem>
<TabItem label="Codex">
```sh
ln -s ~/.rematch/skills ~/.agents/skills/rematch
rematch skills sync --harness codex --cwd "$PWD"
```
Run the sync before starting Codex in a repo.
</TabItem>
</Tabs>

The live adapters trace while you work; Codex uses post-hoc import. Reflection uses omp with model access. See [installation and requirements](/rematch/start/install/) before starting.

## What it will never do without you

<ul class="rm-never">
	<li>Run a script or install a hook. Scripts are staged non-executable; hooks are compiled only after you approve them.</li>
	<li>Change anything beyond your machine. Team and fork changes are branches and PRs; nothing is merged for you.</li>
	<li>Write a repo's <code>AGENTS.md</code> on your machine, or write your personal <code>~/.omp/agent/AGENTS.md</code> without your hash-bound approval.</li>
	<li>Call a change verified. An entry is <code>kept</code> only after four clean sessions of actual use or an authorized comparative probe, and its counts are shown raw.</li>
	<li>Keep running after <code>rematch off</code> or <code>REMATCH=0</code>.</li>
</ul>
